- 육향정원은 정갈한 한우, 모닝페이퍼는 출근길커피로 저장됐다. 메뉴 구성과 출근길 테이크아웃은 원문 근거가 있다. 차분함·산뜻함은 표현 방향이다. 원문에 없는 재료·원산지·수상·경력·숫자는 컨셉에서 발견하지 못했다.
- 모닝페이퍼 아메리카노 메뉴 문구를 같은 저장된 shop_id로 두 번 요청했다. 두 결과 모두 해요체였고 저장된 컨셉은 같았다. 예시 선택은 실제 앱의 랜덤 선택을 사용했다.
