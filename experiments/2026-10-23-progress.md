## 실제 평가 호출

`python -m eval.run_extract --version v1 --ids 2`를 실행했으나, 최초 호출과 재시도 3번 모두 Gemini HTTP 504(Deadline expired)로 실패했다. 결과는 `experiments/runs/v1/2.json`에 보존했다.

- v1: 성공 프로필 없음. 전체 호출 및 채점 미실행. v1 점수는 없음.
- v2: v1 단건 성공 확인에 이르지 못해 호출·채점·비교 미실행.
- 기존 gold 자기검증은 실제 Gemini 추출 성능과 구분해야 함.
- 원문 재표현의 invented 판정, 업종 동의어 판정 검토, v3 작성은 실제 v1/v2 facts.csv 확보 후 진행해야 함. 현재 점수나 틀린 사례를 임의로 만들지 않았음.

## 이어서 실행

```powershell
python -m eval.run_extract --version v1 --ids 2
python -m eval.run_extract --version v1
python -m eval.score --run-name v1
python -m eval.run_extract --version v2
python -m eval.score --run-name v2
```

첫 명령의 성공을 확인한 후 나머지를 진행한다. 성공 캐시는 건너뛰며 실패 ID는 다시 시도한다.

사용자 확인: `http://127.0.0.1:8501`에서 글 입력·저장·불러오기 확인. 정리하기는 외부 Gemini API 장애 영향을 받는다. 코드 검토자는 `tests/test_profile_ui.py`, `tests/test_profile_save_api.py`, `tests/test_shop_store.py`와 실제 facts.csv를 구분해서 검토하면 된다.
