입력: 불꽃한점 / 소갈비살 / 가격·할인·별도 특징 없음. 기존 Gemini 결과는 저장 파일 그대로, GPT 결과는 현재 채팅에서 작성했다. 별도 GPT API 실행이나 동일 temperature 재현 실험은 아니다. 기존 결과를 본 상태에서 작성한 1개 사례이므로 모델 우열을 입증하지 않는다.

## 비교 메모

- 기존 Gemini는 가게 소개와 정중한 초대가 중심이다. GPT 작성본은 질문으로 시작한다.
- 기존 인스타그램의 편안한/편안한/편하게 반복을 GPT 작성본에서는 줄였다.
- 기존의 하루의 피로를 풀어보세요는 일반적인 초대 표현이다. 가격·원산지 같은 허위 사실로 판정하지 않았다.
- 두 결과 모두 입력에 없는 가격·원산지·할인·영업시간을 추가하지 않았다. 순수 함수 숫자·원산지·피할 표현 검사도 통과했다.
- mood_strengths에는 대표 메뉴 설명, tone에는 편안한 가게 느낌이 들어 있다. 문구 모델만이 아니라 입력 필드 분류도 후속 개선 대상이다.
- 실제 Gemini v2 출력은 아직 없으므로 v2와의 비교는 하지 않았다.
